# FDE 入场七步 · 分享会资料包

2026 上海分享会《FDE：明年中国公司只招 AI 人才了》的配套资料。

分享会上屏幕里那些看不清的表格和文档，都在这里了。它们都来自同学们在真实公司里做的项目，已经做过脱敏：公司名、人名、地点、内部链接都换掉了，方法、结构和表格原样保留。

## 怎么用

最省事的用法：**把逐字稿和对应的文档一起丢给 AI**，让它帮你拆。比如：

> 这是一场分享会的逐字稿，和其中第二步用到的调研表。请按这套方法，帮我给【你所在的行业 / 你认识的一家公司】做一份六维调研表和痛点 ROI 排序表。

然后拿你自己的行业，把七步走一遍。走完，你手里就有七样能打开给面试官看的东西。
