> 本文为模拟重建的示例文档：原件为项目内部资料、未随资料包公开，此处根据资料包其他文档的上下文重建，结构与方法可参考，具体数字与细节为示意。

| 项 | 内容 |
|-|-|

## 一、执行摘要

X 集团已经不是"要不要用 AI"的阶段：董事长本人每天早上 9 点前通过个人 Claude 收大宗商品价格推送，已经形成自然语言使用习惯。会上暴露出的真正问题是：

1. **个人 AI 到了天花板**——"聚丙烯还在手动加""手机这两天都没做完"，配置量一上来，个人订阅撑不住；
2. **投后管理靠人催**——上百家被投企业的数据需要研究部、财务部定期催报；
3. **散装使用无法管理**——员工各用各的工具，数据去向不清、产出沉淀不回集团。

我方建议把 X 集团的 AI 使用从"1.0 个人散装"升级为"2.0 企业级、可管理、可控、可沉淀"的组织能力，路径为 **三档递进**：

- **轻档 POC（3 个月，约 ¥5.5 万 – ¥8.5 万）**：投后管理看板 + 1 个投研助手 AI 员工，先解决"老板早报自动化"；
- **中档 部门落地（约 ¥50 万 – ¥100 万 / 年）**：投研、风控、投后三个团队；
- **重档 集团战略合作（约 ¥200 万 – ¥500 万 / 年）**：金融、能源、物业、创投、高科技五板块。

**我们的建议是：先签轻档，T+30 天启动 POC，用 3 个月的结果决定下一档。**

## 二、客户现状与痛点

### 2.1 现状速写

| 维度 | 现状 | 判断 |
|-|-|-|
| AI 使用 | 董事长个人 Claude + 内部关系人维护的每日大宗商品推送 | 早鸟用户，无需从 0 教育 |
| IT 资产 | 已上线通达 OA（合同审批、流程权限）；董事长持有万得账号 | 可直接作为数据源接入 |
| 组织 | 金融 / 能源 / 物业 / 高科技 / 创投多板块，已投项目数十至上百家 | 结构与黑石"多板块 + 大量被投"高度相似 |
| 关注点 | 数据安全（风控负责人追问 3 次）、投入产出比、法律边界 | 合规口是真实决策卡点 |

### 2.2 痛点 ROI 排序（沿用会议整理的 P0 / P1 / P2 排序）

| 优先级 | 痛点 | 现场证据 | 现状方案 | AI 化杠杆 | 落地节奏 |
|-|-|-|-|-|-|
| **P0** | 投后管理：上百家被投企业靠人催数据 | "我要求研究部财务部定期更新，没人报我得催" | 人工 + Excel + 邮件 | 数据找人代替人找数据 → 10 倍人效 | 首期 POC |
| **P0** | 个人 Claude 配置量上来撑不住 | "我手机这两天都没做完，聚丙烯还在手动加" | 个人 Claude 订阅 | AI 员工 24 小时 + 自动早报 | 首期 POC |
| **P1** | 投研报告质量黑盒 | "考 740 vs 考 140 的同一张卷子" | 依赖个人经验 | Agent + 知识库 + 魔鬼代言人 | 二期叠加 |
| **P1** | 合同管理失控 | 风控负责人：合同放桌上找不到、年度未提醒更新 | 通达 OA 1.0 信息化 | 合同审查 Agent + 主动提醒 | 二期叠加 |
| **P2** | 跨板块数据孤岛 | 每天看大宗商品但还要手动加聚丙烯 | 各板块独立 | MCP 连接器统一 → 集团驾驶舱 | 重档 |

## 三、解决方案：五项能力 × 五个痛点

### 3.1 能力说明

| 我方能力 | 是什么 | 在 X 集团怎么用 |
|-|-|-|
| **AI 员工（3 分钟上岗）** | 预装技能 / 工具 / 插件的智能体，按岗位雇佣 | "投研助理""投后预警官""合同审查官"三类岗位 |
| **云电脑独立私有部署** | 每个 AI 员工一台独立云主机，数据与产出都留在主机上，所有权归 X 集团 | 承载 AI 员工 24 小时运行，回应风控负责人的数据安全关切 |
| **智能路由模型池** | 按任务价值自动分配模型：高价值决策走最强模型，重复劳动走国产模型 | 投研结论、投委意见走最强模型；格式整理、摘要走国产模型 |
| **企业知识库 + MCP 连接器** | 把外部数据源和内部系统接成 AI 员工可读的知识 | 首期接万得 + 通达 OA；后续接东方财富、被投企业财报 |
| **虚拟投委会 / 魔鬼代言人** | 多个 Agent 以不同风险偏好（保守 / 逆向 / 成长）审视同一项目 | 把 GIC 的做法落到 X 集团投委会前置环节 |

### 3.2 痛点 × 能力匹配矩阵

| 痛点 | AI 员工 | 云电脑 | 模型路由 | 知识库 MCP | 魔鬼代言人 |
|-|-|-|-|-|-|
| P0 投后管理 | ★★★ | ★★ | ★ | ★★★ | ★ |
| P0 个人天花板 | ★★★ | ★★★ | ★★ | ★★ | - |
| P1 投研黑盒 | ★★ | ★ | ★★★ | ★★★ | ★★★ |
| P1 合同管理 | ★★★ | ★★ | ★ | ★★ | - |
| P2 数据孤岛 | ★ | ★ | - | ★★★ | - |

**结论**：首期落地"投后管理 + 个人 AI 升级"双 POC，3 个月内见效；二期叠加投研 / 合同；重档再做五板块驾驶舱。

## 四、三档方案

> 价目基于我方公开价目卡：专业版 ¥299/月（5 AI 员工）、托管服务全托管 ¥8,000/月、托管按时 ¥200/小时、免费试用 14 天；企业版为定制档。以下区间为合理组合估算，**实际以我方正式报价为准**。

### 🟢 轻档：POC 试点（3 个月）

| 项目 | 计算 | 金额 |
|-|-|-|
| 专业版团队套餐 ×1（5 AI 员工） | ¥299/月 × 3 | ¥897 |
| 托管服务 · 包月全托管 | ¥8,000 × 3 | ¥24,000 |
| 一次性集成开发（接万得 + 通达 OA） | 建议区间，需确认 | ¥30,000 – ¥60,000 |
| **合计** | | **约 ¥5.5 万 – ¥8.5 万 / 3 个月** |

- **范围**：1 个场景（投后管理看板）+ 1 个核心 AI 员工（投研助手）
- **关键 KPI**：3 个月后董事长早报由 AI 员工自动产出，不再手动加聚丙烯

### 🟡 中档：部门级落地（6–12 个月）

| 项目 | 金额 |
|-|-|
| 企业版定制（私有化部署 + 无限 AI 员工 + SLA + 定制 3–5 个 Agent） | 参考 ¥20 万 – ¥50 万 / 年 |
| 托管服务 · 全托管全年（¥8,000 × 12） | ¥9.6 万 |
| 一次性定制开发（魔鬼代言人投委会 + 合同审查官 + 投后预警官） | ¥20 万 – ¥40 万 |
| **合计** | **约 ¥50 万 – ¥100 万 / 年** |

- **范围**：投研部 + 风控部 + 投后部
- **关键 KPI**：投研报告产出周期缩短 50%、合同审查全覆盖、被投企业月度自动健康度推送

### 🔴 重档：集团战略合作伙伴（多年）

| 项目 | 金额 |
|-|-|
| 企业版顶配定制（多套私有化集群 + 跨板块知识库 + 老板战略外脑） | ¥100 万 – ¥300 万 / 年 |
| 7×24 专属工程师团队（¥8,000 × 12 × 多席位） | 约 ¥30 万 – ¥50 万 / 年 |
| 持续定制开发预算 | ¥50 万 – ¥100 万 / 年 |
| 可谈：股权置换 / 联合实验室 / 标杆案例分成 | 另议 |
| **合计** | **约 ¥200 万 – ¥500 万 / 年** |

- **关键 KPI**：3 年内人均产值翻倍、AI 员工数量 > 人类员工数量
