# 某英语学习 App · CMS需求文档

本文为真实项目材料脱敏版，公司名、人名、链接等已替换，仅供学习交流。

## 一、文档定位

本文档用于向产品和技术团队说明教研侧对 CMS 系统的完整需求。该系统不是普通题库后台，而是教研资产生产、审核、发布和追踪的中台。当前题目主要由 Agent 生成，教研团队的核心工作是管理知识库、定义标签和标准、审核并修改 Agent 生成结果、控制题目发布、追踪质量数据，并支持批量上传下载和版本追溯。

本文档先完整描述目标需求，不按一期/二期拆分。具体开发优先级可在产品排期阶段再拆。

剧本生成和改写方面的需求和能力之前和剧本侧负责人单独对过了，在这个文档中就没有重复提出。

### 1.1 建设目标

| 目标 | 说明 |
|-|-|
| **统一管理教研资产** | 集中管理知识点、题目、标签、审核记录、发布版本和数据反馈，避免散落在 Excel、飞书文档和口头沟通中。 |
| **支撑 Agent 出题流程** | Agent 负责批量生成候选题，CMS 负责接收、校验、审核、修改、再生成、发布和追踪。 |
| **保障内容质量** | 通过知识库约束、标签规范、自动校验、人工审核和版本控制，降低错题、超纲题、答案不唯一和标签混乱风险。 |
| **提升批量处理效率** | 支持批量导入、导出、审核、打标、修改状态、下架和发布，适配大规模内容生产。 |
| **形成可追溯闭环** | 每个知识点和题目都能追踪来源、生成参数、修改记录、审核记录、发布记录和线上表现。 |

### 1.2 核心业务对象

| 对象 | 定义 | 主要使用场景 |
|-|-|-|
| **知识点** | 词汇、短语、语法、功能表达等教学最小单元。 | Agent 出题依据、题目审核依据、知识点覆盖分析。 |
| **题目** | 围绕知识点生成或人工创建的练习题，包括题干、选项、答案、解析和标签。 | 审核、修改、发布、组卷、复习调用。 |
| **标签** | 用于描述知识点和题目的结构化属性，包括级别、题型、话题、状态、质量问题等。 | 筛选、批量操作、生成约束、数据统计。 |
| **生成批次** | 一次 Agent 生成任务产生的一组候选题及其参数记录。 | 批量审核、问题追踪、Prompt/Agent 版本评估。 |
| **审核记录** | 教研或审校人员对题目质量的判断、问题标签和修改建议。 | 质量复盘、责任追踪、后续优化。 |
| **发布版本** | 题目上线可调用的冻结版本。 | 线上调用、回滚、下架影响分析。 |

## 二、使用角色与权限

系统需要支持不同角色在同一套 CMS 中协作。权限设计应避免“谁都能直接改已发布内容”的风险，同时保证教研日常审核修改效率。

| 角色 | 主要职责 | 关键权限 |
|-|-|-|
| **教研人员** | 维护知识点、审核 Agent 候选题、修改题目、打标签、提交发布。 | 创建/编辑草稿，批量导入导出，提交审核，发起再生成。 |
| **审校人员** | 复核题目质量，判断是否通过，记录问题和修改建议。 | 审核通过、退回修改、添加质量标签、查看修改历史。 |
| **教研负责人** | 定义标准，控制发布，处理高风险变更和下架。 | 正式发布、下架、归档、知识点核心字段审批、权限配置。 |
| **内容团队** | 查看知识点和题目，用作内容创作参考。 | 只读查看、筛选、导出受限数据。 |
| **产品/技术** | 查看结构化数据和系统调用状态，排查接口或前端问题。 | 只读查看、接口字段查看、日志查看。 |
| **管理员** | 维护基础配置、模板、枚举值、权限和系统字典。 | 配置管理、标签字典管理、导入模板管理、权限管理。 |

### 2.1 权限原则

- 已发布内容不能被直接覆盖编辑；修改已发布题目时，应生成新草稿版本，待审核发布后替换线上版本。
- 删除应区分物理删除和业务下架。未发布草稿可以删除；已发布题目应下架或归档，保留历史记录。
- 知识点的核心字段变更应触发影响分析，展示关联题目、剧集、生成批次和发布内容。
- 批量发布、批量下架、批量删除、知识点废弃等高风险操作需要二次确认和操作记录。

## 三、整体业务流程

CMS 的主流程应围绕“知识库约束 Agent 生成，教研审核并发布”的闭环设计。

```text
维护知识库与标签规范
    ↓
创建 Agent 出题任务
    ↓
Agent 生成候选题
    ↓
系统自动校验
    ↓
教研审核工作台：修改 / 通过 / 退回 / 删除 / 再生成
    ↓
审校或负责人复核
    ↓
发布为线上可调用版本
    ↓
线上数据回流：正确率、耗时、问题反馈
    ↓
教研优化知识点、题目和生成规则
```

### 3.1 状态流转

| 状态 | 含义 | 可执行操作 |
|-|-|-|
| **候选** | Agent 生成后进入候选池，尚未人工确认。 | 查看、编辑、删除、退回再生成、提交审核。 |
| **草稿** | 人工创建或修改中的题目。 | 编辑、保存、删除、提交审核。 |
| **待审核** | 已提交给审校人员或负责人复核。 | 审核通过、退回修改、添加审核问题。 |
| **退回修改** | 未达发布标准，需要教研修改。 | 编辑、再生成、重新提交审核。 |
| **审核通过** | 内容质量通过，但尚未正式上线。 | 发布、退回、查看。 |
| **已发布** | 线上可调用版本。 | 创建新版本、下架、查看数据。 |
| **已下架** | 不再被线上调用，但保留记录。 | 查看、重新提交、归档。 |
| **已归档** | 历史数据保留，只读。 | 查看、导出。 |

## 四、知识库管理需求

知识库是 Agent 出题和教研审核的上游标准。系统应把知识点当作可治理的生产资产，而不是普通资料条目。

### 4.1 知识点数据结构

| 字段 | 说明 | 必填 | 维护方式 |
|-|-|-|-|
| **知识点ID** | 系统唯一 ID，如 KP-B1-0001。 | 是 | 系统生成 |
| **知识点名称** | 标准展示名称，如 make up one's mind。 | 是 | 人工/导入 |
| **标准写法** | 词汇原形、短语标准形式、语法结构名或功能表达名。 | 是 | 人工/导入 |
| **知识点类型** | 词汇、短语、语法、功能表达。 | 是 | 人工选择 |
| **CEFR级别** | A1/A2/B1/B2/C1/C2。 | 是 | 人工/词表校验 |
| **适用学习模式** | 英语学英语、母语学英语，或两者都可。 | 是 | 人工选择 |
| **所属话题** | 可多选，如职场、社交、生活、旅行等。 | 是 | 人工/导入 |
| **功能/语用说明** | 说明该表达用于请求、拒绝、解释、安慰、道歉等何种交际目的。 | 视类型 | 人工 |
| **例句** | 2-3 个符合级别的例句，可含翻译。 | 是 | 人工/导入 |
| **易错点** | 常见误用、混淆点、不可作为干扰项的表达。 | 否 | 人工 |
| **前置知识点** | 学习该知识点前应掌握的知识点。 | 否 | 人工选择 |
| **相似/关联知识点** | 同义、近义、易混、同结构知识点。 | 否 | 人工/系统推荐 |
| **状态** | 草稿、待审核、可用、暂停使用、已废弃。 | 是 | 流程控制 |
| **版本号** | 每次核心字段变更生成新版本。 | 是 | 系统生成 |

### 4.2 知识库核心功能

| 功能 | 需求说明 |
|-|-|
| **查询与筛选** | 支持按名称、ID、级别、类型、话题、适用题型、状态、创建人、更新时间筛选。 |
| **新增与编辑** | 支持单条新增、单条编辑、批量导入。编辑核心字段时记录修改前后差异。 |
| **状态管理** | 只有“可用”知识点可被 Agent 调用；暂停使用和已废弃知识点不可用于新题生成。 |
| **版本管理** | 每次变更生成版本记录，记录修改人、时间、字段差异和修改原因，支持查看和回滚。 |
| **重复检测** | 系统识别名称、标准写法、例句或语义相近的知识点，提示合并或保留。 |
| **合并与迁移** | 重复知识点合并时，题目关联自动迁移到主知识点，并保留旧 ID 映射。 |
| **引用影响分析** | 废弃、改级别、改类型前，展示关联题目数、已发布题目数、生成批次数和调用影响。 |
| **导入导出** | 支持 Excel/CSV 批量导入导出；导入失败需返回失败行、失败字段和失败原因。 |

## 五、题目库与审核工作台需求

题目库是 CMS 的核心工作区。由于题目主要由 Agent 生成，系统应把“候选题审核与修改”作为最高频场景设计，而不是只提供普通题库录入表单。

### 5.1 题目数据结构

| 字段 | 说明 | 必填 | 维护方式 |
|-|-|-|-|
| **题目ID** | 系统唯一 ID。 | 是 | 系统生成 |
| **题型** | 单选、听音选义、语境填空、拼写填空、排序、配对、跟读、复述等。 | 是 | 人工/生成参数 |
| **CEFR级别** | 目标学习级别。 | 是 | 人工/生成参数 |
| **学习模式** | 英语学英语或母语学英语。 | 是 | 人工/生成参数 |
| **知识点ID** | 可关联一个或多个知识点，至少一个主知识点。 | 是 | 人工/Agent |
| **题干** | 展示给用户的题目引导文本。 | 是 | Agent/人工 |
| **选项/输入区** | 按题型配置，如 2 选 1、4 选 1、候选词、配对组、排序词块。 | 视题型 | Agent/人工 |
| **正确答案** | 标准答案，支持结构化答案。 | 是 | Agent/人工 |
| **解析/反馈** | 解释为什么对、为什么错；可按选项配置反馈。 | 是 | Agent/人工 |
| **来源信息** | 来源剧集、来源台词、来源知识点、生成任务。 | 是 | 系统/Agent |
| **媒体资源** | 图片、音频、视频片段、录音评分资源等。 | 视题型 | 上传/引用 |
| **标签** | 级别、题型、话题、质量、状态、发布范围等。 | 是 | 系统/人工 |
| **状态** | 候选、草稿、待审核、退回、审核通过、已发布、已下架、已归档。 | 是 | 流程控制 |
| **Agent版本** | 生成该题所用 Agent/模型/Prompt 版本。 | AI题必填 | 系统记录 |
| **生成批次** | 关联一次生成任务。 | AI题必填 | 系统记录 |
| **原始生成内容** | 保留 Agent 初始输出，用于和人工修改版本对比。 | AI题必填 | 系统记录 |
| **审核记录** | 审核人、审核时间、问题标签、修改建议、处理结论。 | 审核后必填 | 系统/人工 |
| **发布版本** | 已发布题目的线上冻结版本号。 | 发布后必填 | 系统生成 |

### 5.2 审核工作台功能

| 功能 | 需求说明 | 备注 |
|-|-|-|
| **审核队列** | 展示待审核、候选、退回修改题目，支持按生成批次、级别、题型、知识点、状态、问题类型筛选。 | 高频入口 |
| **题目详情页** | 同时展示题目内容、知识点信息、生成来源、标签、审核记录、发布状态和历史版本。 | 核心页面 |
| **用户端预览** | 以接近真实用户端样式预览题干、选项、反馈、音频/图片等资源。 | 减少上线后问题 |
| **逐题编辑** | 支持编辑题干、选项、正确答案、解析、标签、知识点关联、媒体资源和状态。 | 必须就地编辑 |
| **修改前后对比** | 展示 Agent 原始版本、当前编辑版本、历史版本差异，支持回退。 | 便于复盘 |
| **审核结论** | 支持通过、退回修改、删除/弃用、再生成、提交负责人复核。 | 记录原因 |
| **问题标签** | 审核时可标注知识点错配、答案不唯一、干扰项弱、级别偏难、题干不清等问题。 | 支持多选 |
| **批量审核** | 列表中可批量通过、批量退回、批量删除、批量打标、批量导出。 | 需二次确认 |
| **再生成** | 可基于当前题目或知识点重新生成单题，也可对一批题按问题原因批量再生成。 | 保留新旧关联 |

### 5.3 自动校验规则

| 校验项 | 说明 | 系统处理 |
|-|-|-|
| **必填字段** | 题干、题型、级别、知识点、答案、状态等不能为空。 | 阻断提交/发布 |
| **题型结构** | 选项数、答案数、配对组数、排序词块、录音资源等需符合题型规则。 | 阻断提交/发布 |
| **答案唯一性** | 判断是否存在多个可接受答案或正确答案错误。 | 提示人工复核 |
| **知识点匹配** | 题目是否围绕主知识点，不应考查无关知识点。 | 提示人工复核 |
| **级别适配** | 检查词汇、句长、语法、选项难度是否高于目标级别。 | 提示人工复核 |
| **重复题检测** | 同知识点下题干、选项或答案高度相似时提示。 | 提示合并/保留 |
| **资源有效性** | 音频、图片、视频是否可访问，是否与题型匹配。 | 阻断发布 |
| **标签完整性** | 必填标签缺失时不可发布。 | 阻断发布 |

## 六、Agent 出题与生成任务管理

系统需要把 Agent 生成当作可管理任务，而不是一次性导入结果。每次生成都应有任务记录、参数记录、结果池和质量反馈。

### 6.1 生成任务创建

| 参数 | 说明 |
|-|-|
| **知识点范围** | 可选择单个知识点、多个知识点、某级别下未覆盖知识点、某话题知识点。 |
| **题型范围** | 可指定一种或多种题型；系统应提示该知识点是否适合所选题型。 |
| **级别与学习模式** | 选择 CEFR 级别和英语学英语/母语学英语模式。 |
| **题目数量** | 设置每个知识点生成几题、总生成数量、每题型数量。 |
| **生成说明** | 允许教研补充本批次特别要求，如避免某类干扰项、重点考功能表达。 |
| **Prompt/Agent版本** | 系统自动记录，不允许丢失。 |

### 6.2 生成结果管理

- Agent 生成结果默认进入“候选”状态，不允许自动进入已发布。
- 每道题保留原始 JSON、生成参数、生成时间、Agent 版本和 Prompt 版本。
- 同一批次题目支持批量查看、批量导出、批量审核和批量再生成。
- 教研修改后，系统保留“原始生成题”和“人工修改题”的差异。
- 若题目被退回或删除，应记录原因，供后续优化 Agent Prompt。

### 6.3 再生成需求

| 场景 | 需求说明 |
|-|-|
| **单题再生成** | 在题目详情页点击再生成，系统带入原知识点、级别、题型和问题原因。 |
| **批量再生成** | 选择一批题目，按相同问题原因重新生成，如“干扰项弱”“题干不清”“级别偏难”。 |
| **保留旧题** | 再生成不覆盖旧题，旧题可保留为废弃版本或候选版本。 |
| **生成质量追踪** | 统计不同 Agent/Prompt 版本的通过率、退回率、常见问题类型。 |

## 七、标签体系需求

标签是 CMS 的核心导航系统，需要服务于 Agent 生成、人工审核、批量管理、发布控制、组卷和数据分析。标签不能只是展示字段，必须可筛选、可批量维护、可追踪变更。

### 7.1 标签分类

| 标签类别 | 示例 | 说明 |
|-|-|-|
| **基础属性标签** | CEFR级别、题型、学习模式、知识点类型 | 系统必填字段，主要来自题目或知识点结构。 |
| **内容标签** | 话题、场景、功能意图、语法点、词汇域 | 用于筛选、生成约束和内容覆盖分析。 |
| **质量标签** | 答案不唯一、干扰项弱、题干不清、级别偏难 | 审核时使用，支持严重程度和修改建议。 |
| **流程标签** | AI生成、人工修改、待复审、已发布、已下架 | 用于追踪题目处理阶段和来源。 |
| **数据标签** | 高错题、低区分度、答题过慢、长期未调用 | 由线上数据自动生成，供后续优化。 |
| **发布标签** | 可上线、灰度中、仅测试、不可发布 | 控制题目是否可被业务正式调用。 |

### 7.2 标签管理能力

- 支持标签字典管理，包括新增、禁用、合并、重命名和层级关系维护。
- 支持批量打标、批量删标、批量替换标签。
- 标签变更需记录操作人、时间、变更前后内容。
- 系统自动标签和人工标签需区分来源。
- 删除或合并标签前，应展示受影响知识点和题目数量。

## 八、批量上传、下载与数据导入导出

教研工作存在大量批量处理场景，CMS 必须支持稳定的批量能力，并提供清晰的失败反馈。

### 8.1 批量上传

| 需求 | 说明 |
|-|-|
| **模板下载** | 提供知识点模板、题目模板、标签模板、审核结果模板。模板需有版本号。 |
| **字段校验** | 上传后校验必填字段、字段格式、枚举值、知识点 ID、题型规则、重复数据。 |
| **失败反馈** | 返回失败行、失败字段、失败原因，并允许下载错误报告。 |
| **预览确认** | 正式导入前展示本次将新增、更新、跳过、失败的数据数量。 |
| **批量更新** | 支持按 ID 更新已有数据，如批量改标签、状态、知识点关联、解析。 |

### 8.2 批量下载

- 支持按筛选条件导出知识点、题目、审核记录、生成批次、发布记录、问题标签和数据指标。
- 导出字段可配置，默认使用教研常用字段模板。
- 支持导出为 Excel/CSV；大批量导出可异步生成并通知下载。
- 导出内容需遵守权限，只读角色不能导出敏感字段或完整发布数据。

## 九、发布与生命周期管理

发布是 CMS 的高风险动作。系统需要保证只有通过审核并满足校验规则的题目才能进入线上调用。

### 9.1 发布前校验

- 题目状态必须为审核通过。
- 必填字段、必填标签、知识点关联和资源文件必须完整。
- 题型结构必须符合规则，例如选项数、配对组数、答案数量等。
- 存在高风险问题标签时，不允许发布，除非负责人强制确认并记录原因。
- 发布前展示影响范围，包括将被哪些课程、剧集、练习、复习系统调用。

### 9.2 发布后管理

| 能力 | 需求说明 |
|-|-|
| **版本冻结** | 已发布版本不可直接编辑，任何修改都生成新草稿版本。 |
| **版本替换** | 新版本审核发布后替换线上版本，旧版本进入历史记录。 |
| **下架** | 下架需填写原因，如答案错误、级别不符、数据表现异常、资源失效。 |
| **回滚** | 支持回滚到上一发布版本，并记录回滚原因和操作人。 |
| **灰度发布** | 可选支持小范围发布，用于新题型或新 Agent 生成策略验证。 |

## 十、数据看板与质量追踪

看板应服务于教研质量决策，而不是单纯展示数量。需要能发现知识点覆盖缺口、题目质量问题、审核效率问题和 Agent 生成质量问题。

| 看板 | 指标 | 用途 |
|-|-|-|
| **知识点覆盖** | 各级别、话题、知识点类型的题目数量和覆盖率。 | 发现缺题知识点。 |
| **审核进度** | 候选题数、待审核数、退回数、发布数、平均审核时长。 | 管理教研产能。 |
| **质量问题** | 问题标签分布、严重问题数量、常见退回原因。 | 优化标准和 Agent Prompt。 |
| **Agent质量** | 不同 Agent/Prompt 版本的通过率、修改率、退回率。 | 评估生成效果。 |
| **线上表现** | 正确率、平均答题时长、跳过率、投诉/反馈。 | 发现需优化或下架题目。 |
| **批量任务** | 导入成功率、失败原因、导出次数、批量操作记录。 | 追踪数据处理稳定性。 |

## 十一、接口与系统协同需求

CMS 需要与 Agent 出题系统、前端展示系统、复习/组卷系统和数据分析系统协同。

| 协同对象 | 需求说明 |
|-|-|
| **Agent出题系统** | 读取可用知识点和标签规则；写入生成批次、候选题、生成参数和原始输出。 |
| **前端展示系统** | 读取已发布题目版本、题型结构、资源文件和反馈内容。 |
| **复习/组卷系统** | 按知识点、级别、题型、状态、发布范围调用题目。 |
| **数据分析系统** | 回传答题正确率、耗时、跳过率、题目调用量和用户反馈。 |
| **权限系统** | 同步用户角色和操作权限，记录高风险操作日志。 |

## 十二、验收标准

产品和技术实现时，建议至少按以下标准验收，确保系统真正服务教研生产，而不是只完成后台字段录入。

| 验收方向 | 验收标准 |
|-|-|
| **知识库** | 教研可以完成知识点新增、编辑、状态管理、批量导入导出、版本追踪和引用影响查看。 |
| **Agent题接收** | Agent 生成题能进入候选池，并保留生成批次、Prompt/Agent 版本和原始输出。 |
| **审核修改** | 教研可以在同一页面预览、修改、打标、通过、退回、删除或再生成题目。 |
| **批量能力** | 能批量上传、下载、打标、审核、改状态、发布和下架，并返回失败原因。 |
| **发布安全** | 未审核或字段不完整的题目不能发布；已发布题目修改会生成新版本。 |
| **追溯能力** | 任一题目都能追溯知识点、生成来源、人工修改、审核记录、发布版本和线上表现。 |
| **数据看板** | 能查看知识点覆盖、审核进度、质量问题、Agent 质量和线上题目表现。 |
