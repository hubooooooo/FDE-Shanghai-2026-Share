# B1/B2/C1 英语短剧剧本语言与知识点要求

本文为真实项目材料脱敏版，公司名、人名、链接等已替换，仅供学习交流。

> **使用目的：**本文档用于前置发给编剧，约束剧本生成时的台词语言、词汇级别、标黄知识点、知识点数量和语言自然度。本文不规定交付格式，只规定后续审核会直接检查的语言与 Learning 质量标准。

## 一、核心审核口径

请先区分两个概念：台词词汇占比看的是正式英文台词的广义 CEFR 难度；标黄知识点看的是是否命中项目词表对应级别 sheet。两者不混用。

| 项目 | 口径 | 编剧执行要点 |
|---|---|---|
| 台词词汇占比 | 不看 KB/项目词表命中率，只按广义 CEFR 判断正式英文台词中的有效内容词；按 rewrite v5.0 的目标级别分布审核。 | 目标级别内容词要自然出现，不要硬塞；支撑级别词承担叙事主体，高于目标级别的残留要严格控制。 |
| 标黄知识点 | 必须 100% 命中飞书对应级别 sheet；命中其他级别、未在 A1-C2、或短语未命中均不合格。词形命中需要标回对应级别 sheet 原型。 | 如果目标是 B2，标黄项必须命中 B2 sheet；如果目标是 B1/C1，则必须命中 B1/C1 对应 sheet。 |
| 知识点数量 | 按约 45 秒出现 1 个知识点估算，折算约 90 个英文台词词/知识点；每集允许 ±1 个浮动。 | 台词少的集数不要机械塞 3 个知识点；台词多的集数可以按比例增加。 |
| 语言质量 | 审核会检查拼写、语法、标点、搭配、口语自然度、角色语气、台词可演性和翻译腔。 | 不要只追求级别比例；英文必须像真实角色在当下情境中会说的话。 |

## 二、各级别台词词汇占比要求

### B1 剧本

| 类别 | 目标比例 | 写作要求 |
|---|---|---|
| A1+A2 支撑词 | 70%-80% | 基础词承担叙事主体，保证 B1 剧本可懂、自然、轻负担。 |
| B1 内容词 | 15%-25% | 用 B1 词承载计划、经历、问题解决、简单观点、关系冲突和日常选择。 |
| B2 及以上内容词 | 不超过 5% | 除非剧情必须，避免抽象、书面、专业化表达；优先替换为 B1。 |

### B2 剧本

| 类别 | 目标比例 | 写作要求 |
|---|---|---|
| B1 及以下 支撑词 | 75%-80% | 承担从基础叙事到 B2 表达的过渡，避免难度跳跃。 |
| B2 内容词 | 15%-20% | 用 B2 词承载冲突协商、观点解释、权衡利弊、澄清误会、表达后果。 |
| C1 及以上内容词 | 不超过 5% | 避免过高阶、过抽象、过文学化；能用 B2 就不用 C1/C2。 |

### C1 剧本

| 类别 | 目标比例 | 写作要求 |
|---|---|---|
| B2 及以下 支撑词 | 70%-80% | 中级和中高级词仍承担主要叙事，避免 C1 剧本变成满篇高阶词。 |
| C1 内容词 | 15%-25% | 用 C1 词承载复杂关系、隐含态度、价值判断、立场 nuance、文化/社会议题。 |
| C2 内容词 | 不超过 2% | 避免高度文学化、晦涩、专业化或修辞密度过高；除非角色和剧情强需求。 |

## 三、标黄知识点要求

标黄知识点是教学设计，不等于台词中所有目标级别词。只有真正准备教、且命中对应级别 sheet 的词/短语，才能标黄。

| 规则 | 要求 | 不合格情况 |
|---|---|---|
| 命中对应级别 sheet | B1 剧本标黄项必须命中 B1 sheet；B2 命中 B2 sheet；C1 命中 C1 sheet。 | 命中其他级别、不在 A1-C2、或仅凭经验判断为目标级别，均不合格。 |
| 词形标回原型 | 台词里可以出现词形变化，但知识点/生词表要标回 sheet 中的 Base Word。 | 例如 sheet 是 appreciate，就不要在知识点表里写 appreciates。 |
| 短语整条命中 | 标短语时，短语本身必须在对应级别 sheet 中存在。 | 不能因为其中某个词命中，就把未收录短语作为知识点。 |
| 只标正式台词 | 标黄项必须是角色真实说出口的英文台词。 | 括号内情绪词、舞台描述、音效、角色名、世界观专名不能作为知识点。 |

## 四、知识点数量要求

知识点数量按台词承载能力设置，不按“每集固定几个”机械配置。

| 正式英文台词词数 | 建议知识点数量 | 说明 |
|---|---|---|
| 少于 90 词 | 1-2 个 | 短集不要硬塞 3 个以上知识点。 |
| 90-170 词 | 1-3 个 | 常规短剧单集通常落在此区间。 |
| 171-260 词 | 2-4 个 | 台词明显较多时，可以按比例增加。 |
| 260 词以上 | 按 90 词/点估算，允许 ±1 | 例如 330 词约 3-5 个知识点。 |

## 五、语言硬性错误与自然度要求

以下问题会直接进入审核报告。编剧交付前应逐集检查并修正。

| 问题类型 | 写作要求 | 需避免的例子 |
|---|---|---|
| 拼写/标点/冠词 | 必须检查拼写、大小写、句号、逗号、缩写、a/an/the。 | effectiency、severe.. don't、a honor。 |
| 固定搭配错误 | 常见表达必须按英语固定搭配写。 | get straight to the direct point 应为 get straight to the point。 |
| 翻译腔/中式表达 | 优先使用英语自然说法，不要逐字映射中文。 | you several、Mass numbers of、movement is standard。 |
| 语域不匹配 | 日常、暧昧、冲突、吐槽场景用口语；正式场景才用更正式表达。 | Where is the bathroom located? 在日常场景中过于正式。 |
| 角色标注/称号错误 | 角色名、称号顺序、括号动作形式必须统一。 | Livia Princess 应为 Princess Livia；SERA (smile) 应为 SERA (smiling)。 |
| 舞台描述误作台词 | 冒号后的内容必须是角色说出口的话。 | Kyle: Kyle grits his teeth... 这类动作重复不是台词。 |

## 六、禁止项与高风险项

- 禁止为了凑目标级别比例，在一句话里连续堆多个目标级别词。
- 禁止把低级词、高级词或未入 A1-C2 的词标成目标级别知识点。
- 禁止把括号里的情绪词、动作提示、舞台描述、音效、角色名作为知识点。
- 禁止把语法结构当作词汇/短语知识点，除非对应级别 sheet 已收录该短语。
- 避免敏感/低俗笑点，包括身体羞辱、身份刻板印象、取向玩笑、暴力羞辱等；如剧情必须出现，表达需得体。
- 避免台词解释过多、信息密度过高、角色连续独白过长。

## 七、最小合格标准

| 项目 | 口径 |
|---|---|
| 台词词汇占比 | 不看 KB/项目词表命中率，只按广义 CEFR 判断正式英文台词中的有效内容词。整体剧集按上文对应级别比例审核；单集目标级别词汇占比可放宽至 10%-25%；5% 以内的集数实在做不到时，可以接受 5%-30%。 |
| 标黄知识点 | 必须 100% 命中飞书对应级别 sheet；命中其他级别、未在 A1-C2、或短语未命中均不合格。词形命中需要标回对应级别 sheet 原型。 |
| 知识点数量 | 按约 45 秒出现 1 个知识点估算，折算约 90 个英文台词词/知识点；每集允许 ±1 个浮动。 |
| 语言质量 | 不得有明显拼写、语法、标点、搭配、说话人标注硬伤；英文台词应自然、口语化、符合角色语气，可直接表演。 |
| 建议 | 尝试单集改写；语言问题直接按审核报告 AI 优化，知识点问题按对应级别 sheet 回查后替换。 |

## 八、可直接复制给编剧 Agent 的 Prompt

以下内容可直接复制给编剧或编剧自己的 agent。使用时把“目标级别”和“剧集信息”替换成实际项目要求。

**编剧 Agent Prompt**

```text
你是一名英语学习短剧编剧。请根据以下要求生成/改写目标级别为【B1 / B2 / C1】的英文学习短剧台词。

一、核心目标
1. 剧情要自然成立，台词要像真实角色会说出口的话，可直接表演。
2. 不要为了凑词汇级别硬塞生词；目标级别词必须服务剧情冲突、人物关系、情绪变化或信息推进。
3. 台词词汇占比和标黄知识点是两套不同标准：台词词汇占比按广义 CEFR 判断；标黄知识点必须命中项目对应级别 sheet。

二、台词词汇占比要求
只统计正式英文台词中的有效内容词；不统计角色名、括号内情绪/动作、舞台描述、音效、专有名词、功能词、代词、介词、助动词等。

如果目标级别是 B1：
- A1+A2 支撑词 70%-80%。
- B1 内容词 15%-25%。
- B2 及以上内容词不超过 5%。

如果目标级别是 B2：
- B1 及以下支撑词 75%-80%。
- B2 内容词 15%-20%。
- C1 及以上内容词不超过 5%。

如果目标级别是 C1：
- B2 及以下支撑词 70%-80%。
- C1 内容词 15%-25%。
- C2 内容词不超过 2%。

审核最低合格放宽口径：
- 整体剧集按上面的对应级别比例审核。
- 单集目标级别词汇占比可放宽至 10%-25%。
- 若 5% 以内的集数受剧情限制实在做不到，可接受 5%-30%，但不能成为普遍情况。

三、标黄知识点要求
1. 标黄知识点必须 100% 命中飞书对应级别 sheet：B1 剧本命中 B1 sheet，B2 剧本命中 B2 sheet，C1 剧本命中 C1 sheet。
2. 命中其他级别、未在 A1-C2、或短语未命中，均不合格。
3. 台词里可以出现词形变化，但知识点表里要标回 sheet 中的 Base Word 原型。
4. 如果标短语，短语整条必须命中 sheet，不能只因其中某个单词命中就标为知识点。
5. 不要把角色名、世界观专名、括号里的情绪词、舞台描述、音效标为词汇知识点。

四、知识点数量要求
按约 45 秒出现 1 个知识点估算，折算为约 90 个英文台词词/知识点，每集允许上下浮动 1 个。
- 少于 90 词：建议 1-2 个。
- 90-170 词：建议 1-3 个。
- 171-260 词：建议 2-4 个。
- 260 词以上：按 90 词/点估算，允许 ±1。

五、语言质量要求
1. 不得有明显拼写、语法、标点、冠词、固定搭配错误。
2. 台词要口语化、自然、符合角色身份和情绪，不要中文直译或说明文腔。
3. 单句尽量控制在 8-18 词；必要长句要拆分。
4. 不要让角色长篇解释；用互动推进信息。
5. 同一角色的称呼、语气、关系距离要保持一致。
6. 避免过度正式、过度书面、过度抽象或过度文学化。

六、禁止项
- 不要为了凑目标级别比例，在一句话里连续堆多个目标级别词。
- 不要把低级词、高级词或未入 A1-C2 的词标成目标级别知识点。
- 不要把括号里的情绪词、动作提示、舞台描述、音效、角色名作为知识点。
- 避免敏感/低俗笑点；如剧情必须出现，表达需得体。

七、生成前请先自检
- 目标级别词汇比例是否接近要求？
- 高于目标级别的词是否过多？
- 标黄知识点是否全部命中对应级别 sheet？
- 知识点数量是否符合约 90 词/点？
- 台词是否自然可演？
- 是否存在拼写、冠词、标点、搭配或角色标注硬伤？

请输出：
1. 分集英文正式台词。
2. 每集标黄知识点列表，格式为“第 X 集：LEVEL-Base Word、LEVEL-Base Word”。
3. 简短自检说明：本集目标级别词汇如何自然融入、知识点为什么适合本集剧情。
```
