# 题目测评标准－内容侧

> 本文为模拟重建的示例文档：原件为项目内部资料、未随资料包公开，此处根据资料包其他文档的上下文重建，结构与方法可参考，具体数字与细节为示意。

> **名称说明：**本文在项目中也称《内容侧视频评测标准》（课程制作 Step 11 引用的即本文）。虽然标题沿用“题目测评标准”，实际审核对象是 AI 生成的剧情视频、互动视频和字幕，与《题目测评标准－教研侧》共同构成双维度审核。

|-|-|
| 文档状态 | 视频验收正式规范（V1.0） |
| 维护人 | 编导负责人 |
| 使用人 | 编导团队、内容团队审核人员 |

## 一、审核流程

1. 审核人先通读本集正式剧本（对应等级版本），再完整观看一遍成片，不暂停，记录整体观感。
2. 第二遍按八个维度逐项检查，问题记录到时间码（精确到秒）和镜头号。
3. 每个维度打 1–5 分，并标注问题严重程度；一票否决项一经出现，直接判不通过。
4. 问题退回视频制作环节，修改后只复审受影响镜头与相邻镜头，但综合可用性需重新评分。
5. 互动视频单独审核，重点看与正片的衔接和讲解分支完整性。

## 二、评分规则

| 分值 | 含义 |
|-|-|
| 5 | 无问题，可作为示范 |
| 4 | 有轻微瑕疵，普通用户几乎察觉不到 |
| 3 | 有可察觉问题，但不影响理解和观看 |
| 2 | 问题明显，影响观看体验或理解 |
| 1 | 严重问题，不可上线 |

**通过阈值：**八项总分 ≥ 32（满分 40），且任何单项不低于 3 分，且无一票否决项。“剧本与叙事”“AI 技术一致性”两项权重最高，任一项低于 4 分时，需编导负责人复看确认后才能通过。

**一票否决项：**主角外观在同一集内明显变成另一个人；台词与正式剧本不一致导致知识点台词缺失或改变；字幕与语音不匹配超过 1 秒且多处出现；出现不当、暴力或歧视性画面；关键剧情（如身份反转）缺失。

## 三、八个维度检查点

### 3.1 剧本与叙事

| 检查点 | 标准 |
|-|-|
| 台词忠实度 | 成片台词与对应等级正式剧本逐句一致，知识点台词完整、发音清楚 |
| 剧情完整 | 冲突、转折、结尾钩子完整，场次顺序与剧本一致 |
| 因果清楚 | 观众能理解人物为什么这样做 |
| 示例 | 第二集 2-1 必须清楚呈现“护照被盗—无法确认身份—拒绝入住—认出面具舞伴”；Jacob 说出 verify your identity 的台词不能被剪掉或改写 |

### 3.2 导演与镜头

| 检查点 | 标准 |
|-|-|
| 景别与调度 | 对话戏有正反打，关键反应有近景；不出现无意义长镜头 |
| 轴线 | 不越轴，人物左右位置在同一场内保持稳定 |
| 节奏 | 情绪高点镜头时长足够，片中题时间点附近镜头稳定，便于定格 |
| 示例 | Sophia 认出 Jacob 的瞬间应给到 Sophia 近景反应，再给 Jacob 的回应，避免两人同框远景一带而过 |

### 3.3 摄影与美术

| 检查点 | 标准 |
|-|-|
| 场景一致 | 同一场景的空间布局、陈设、光线方向前后一致 |
| 色调 | 与剧集整体色调一致，同场不跳色 |
| 道具 | 关键道具清楚可见、前后一致 |
| 示例 | 威尼斯民宿的前台、钥匙架、窗外运河在各镜头中位置一致；狂欢节面具若作为回忆道具出现，款式须与前集一致 |

### 3.4 表演与角色

| 检查点 | 标准 |
|-|-|
| 人设一致 | 角色性格、语气与剧本和前集一致 |
| 情绪准确 | 表情、肢体与台词情绪匹配 |
| 示例 | Sophia 的紧张、无助到惊喜要有层次；Jacob 前段冷淡警惕，认出后态度变化要可见，不能全程同一表情 |

### 3.5 声音

| 检查点 | 标准 |
|-|-|
| 口型同步 | 语音与口型偏差不超过 0.2 秒（约 5 帧） |
| 音色一致 | 同一角色音色在全剧保持一致 |
| 清晰度 | 对白清楚，背景音乐和环境音不压人声；知识点台词周围避免强音效 |
| 发音 | 英文发音标准，重音正确，符合角色设定的口音 |
| 示例 | Jacob 说 “I cannot verify your identity.” 时口型、语音同步，verify 发音清楚，可直接截取作听音选择素材 |

### 3.6 后期

| 检查点 | 标准 |
|-|-|
| 剪辑 | 无跳帧、黑帧、重复帧；转场自然 |
| 字幕 | 英文字幕与语音逐句对应，时间轴偏差 ≤ 0.5 秒，无错别字、与正式剧本一致 |
| 调色与混音 | 全片响度统一，镜头间亮度色彩衔接 |
| 时长 | 与剧集登记时长一致，片中题时间点均落在视频时长内 |

### 3.7 AI 技术一致性

| 检查点 | 标准 |
|-|-|
| 外观连续 | 脸型、发型、服装、配饰在镜头之间、集与集之间连续 |
| 画面稳定 | 无肢体畸变、手指异常、面部闪烁、背景漂移 |
| 物理合理 | 物体不凭空出现或消失，光影方向合理 |
| 文字与标识 | 画面中的文字不出现乱码；无真实品牌标识 |
| 示例 | Sophia 的发型、外套、耳环在 2-1 全集保持一致；Jacob 的制服在前台戏和回忆戏的区分符合剧本设定 |

### 3.8 综合可用性

| 检查点 | 标准 |
|-|-|
| 学习可用 | 知识点台词清楚可听、可截取，字幕可读 |
| 互动衔接 | 片中题时间点画面可定格，互动视频与正片无缝衔接，答对／答错讲解两个分支都完整 |
| 移动端观看 | 竖屏构图下主体在安全区内，字幕不遮挡人物面部 |
| 整体观感 | 普通用户愿意继续看下一集 |
| 示例 | 在 Jacob 拒绝入住后的时间点，定格画面清楚，进入题目“为什么 Jacob 不能让 Sophia 入住？”后，讲解分支回到原画面不跳台词 |

## 五、与其他标准的关系

- 题目层面的问题（答案、选项、知识点）不在本文打分，发现后转交教研侧，按《题目测评标准－教研侧》处理。
- 视频审核通过后，编导负责人在 Step 17 完成剧集内容维度签字；教研负责人完成知识点与题目维度签字；两者都完成才进入整体确认。
- 视频发布后发现问题，不直接覆盖，按《CMS 发布与生命周期管理》召回旧版本、修正后发布新版本。
