## 一、操作总览

```text
原子内容已入库（剧本／正片／字幕／知识点／片中题／互动视频／角色／封面）
      ↓
【A】创建剧集：绑定正片 → 绑定字幕 → 关联知识点 → 配置片中题时间点
      ↓
剧集自检通过（单集检查）
      ↓
【B】组成短剧：按集序加入剧集 → 配置等级、封面、人物、角色
      ↓
短剧自检通过（集序与资产检查）
      ↓
交给出题与组装负责人组装课程（Step 17）
```

原则：**先单集、后整剧**。剧集未通过单集检查，不能加入短剧；短剧不复制剧集内容，只按顺序引用剧集 ID。

## 二、创建剧集

### 2.1 剧集字段

| 字段 | 必填 | 填写人 | 说明 |
|-|-|-|-|
| 剧集 ID | 是 | 系统按规则生成 | 如 Episode-SampleDrama-B2-EN-E02-1 |
| 剧集标题 | 是 | 编导 | App 展示用，如“第二集 2-1 威尼斯民宿” |
| 源剧本编号 | 是 | 编导 | 中文原始剧本中的集-段编号，如 2-1 |
| 语言 / 等级 | 是 | 编导 | 必须与绑定的剧本、知识点一致 |
| 正式剧本 | 是 | 编导 | 选择已入库的 Script ID，只能选正式剧本 |
| 正片视频 | 是 | 编导 | 选择 MAIN 类型视频；转码未完成不可选 |
| 字幕 | 是 | 编导 | 至少 1 条与正片匹配的字幕 |
| 时长 | 是 | 系统读取 | 由正片转码结果自动回填，不可手填 |
| 知识点 | 是 | 教研 | 至少 1 个，最多 3 个核心知识点 |
| 片中互动题 | 是 | 教研 | 至少 1 道，含时间点与顺序 |
| 剧集简介 | 否 | 编导 | 不超过 60 字，避免剧透反转 |
| 状态 | 是 | 系统 | 草稿 → 待审核 → 审核通过 |

### 2.2 绑定正片和字幕

1. 在剧集草稿中选择正式剧本，系统按剧本 ID 推荐同集的正片和字幕。
2. 选择正片后，系统回填时长；若正片版本与剧本版本不对应，给出提示。
3. 绑定字幕时，系统检查：字幕最后一条时间不超过正片时长；字幕文本与正式剧本对白一致率低于阈值（示意 95%）时提示编导人工核对。
4. 字幕与视频不匹配属于发布阻断项，必须替换后重新检查。

### 2.3 关联知识点

| 检查 | 规则 |
|-|-|
| 等级一致 | 知识点 CEFR 级别与剧集等级一致（B2 剧集只关联 B2 知识点） |
| 状态可用 | 只能选择“可用”状态的知识点；暂停使用、已废弃不可选 |
| 出现在台词中 | 知识点必须在正式剧本中被标注，系统按剧本标注回查；未出现在台词中的不可关联 |
| 数量 | 按约 90 个英文对白词 1 个、±1，每集最多 3 个 |

### 2.4 配置片中题时间点

| 字段 | 说明 |
|-|-|
| 片中题 ID | 选择已入库的 IQ 题目 |
| 出现时间 | 精确到秒，必须在正片时长内 |
| 顺序 | 系统按时间自动排序，顺序必须递增、不可重复 |
| 配套互动视频 | 进入题目—出题—等待—答对／答错讲解—返回剧情的互动片段 |
| 题目类别 | 知识点题 / 剧情理解题 |

注意：

- 时间点由生产侧固定，避开关键反转镜头和人物说话中途。
- 生产侧可以配置多个候选时间点；用户实际看到哪些题由服务端分发决定（按视频时长控制上限、被选中题目间隔 > 45 秒）。生产侧配置的相邻时间点也建议保持 45 秒以上，避免分发时可用题过少。
- 片中题必须为“已发布”状态才能通过 Step 17 检查；剧集草稿阶段可以先关联审核通过的题目。

## 三、组成短剧

### 3.1 短剧字段

| 字段 | 必填 | 说明 |
|-|-|-|
| 短剧 ID | 是 | 如 Drama-SampleDrama-B2-EN |
| 短剧名称 | 是 | 如《示例短剧》B2 英文版 |
| 语言 / 等级 | 是 | 所有剧集必须同一语言、同一等级 |
| 剧集列表 | 是 | 至少 1 集，按集序排列 |
| 封面 | 是 | 选择设计上传的 Cover，尺寸符合规格 |
| 人物 | 是 | 选择 Char，如 Sophia、Jacob |
| 角色 | 是 | 每个人物选择本版本使用的 Role，如 Role-SampleDrama-Sophia-B2 |
| 简介 | 是 | 面向用户的故事简介 |

### 3.2 集序规则

- 集序从 1 开始连续编号，**不能跳号、不能重复**。
- 同一剧集不能在同一部短剧中出现两次。
- 调整顺序后系统重新校验；集序变化会影响“每 5 集复习”的分组，需通知出题与组装负责人。
- 源剧本编号（如 2-1、2-2）只用于追溯，App 展示与连续性校验以 CMS 集序为准。

### 3.3 人物与角色检查

- 短剧中每个剧集出现的人物，都必须在短剧的人物列表中。
- 每个人物必须选定一个角色版本，且角色对应该人物（不能把 Jacob 的立绘配给 Sophia）。
- 角色错误属于发布阻断项，由编导负责人退回设计修正。

## 四、示例：第二集 2-1 威尼斯民宿

剧情：Sophia 在威尼斯民宿说明钱包和护照被盗；Jacob 因无法确认身份拒绝她入住；最后揭示两人在狂欢节上见过。

| 配置项 | 值（示意） |
|-|-|
| 剧集 ID | Episode-SampleDrama-B2-EN-E02-1 |
| 剧集标题 | 第二集 2-1 威尼斯民宿 |
| 正式剧本 | Script-SampleDrama-B2-EN-E02-1（v1） |
| 正片 | Video-SampleDrama-B2-EN-E02-1-MAIN，时长 02:48 |
| 字幕 | Sub-SampleDrama-B2-EN-E02-1-EN |
| 知识点 | verify your identity（KP-B2-0412）；report a theft（KP-B2-0388）；under the law（KP-B2-0957，台词形式 Under Italian law）——共 3 个最终核心知识点，按台词量确定 |
| 片中题 1 | IQ-…-E02-1-01，01:16，剧情理解题：“为什么 Jacob 不能让 Sophia 入住？” |
| 片中题 2 | IQ-…-E02-1-02，02:21（与题 1 间隔 65 秒），知识点题：verify your identity |
| 人物 / 角色 | Char-SampleDrama-Sophia / Role-SampleDrama-Sophia-B2；Char-SampleDrama-Jacob / Role-SampleDrama-Jacob-B2 |

完成后，将该剧集按集序加入 Drama-SampleDrama-B2-EN，检查前后剧集集序连续，再提交出题与组装负责人组装课程。

## 五、常见退回原因

| 问题 | 退回给 |
|-|-|
| 字幕与正片不匹配、字幕超出视频时长 | 编导负责人 |
| 知识点等级与剧集不一致，或未出现在正式台词中 | 教研负责人 |
| 片中题时间超出视频、顺序不递增 | 教研负责人 + 编导负责人 |
| 集序跳号或重复 | 编导负责人 |
| 角色与人物不对应、封面规格错误 | 编导负责人 → 设计负责人 |
