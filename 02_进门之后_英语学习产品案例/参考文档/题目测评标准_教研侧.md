# 题目测评标准－教研侧

> 本文为模拟重建的示例文档：原件为项目内部资料、未随资料包公开，此处根据资料包其他文档的上下文重建，结构与方法可参考，具体数字与细节为示意。

| 项目 | 内容 |
|-|-|
| 文档状态 | 题目验收正式规范（V1.1） |
| 维护人 | 教研负责人 |
| 使用人 | 教研人员、审校人员、教研负责人 |
| 适用对象 | 片中互动题（知识点题与剧情理解题）、文本练习题；所有等级与学习方式 |
| 使用位置 | 课程制作 Step 9 题目审核；Step 17 知识点与题目维度签字 |
| 配套工具 | CMS 审核工作台（问题标签与本文八项一一对应） |

## 一、审核总则

1. 每道题按 **知识点、题型、语言、等级、选项、题干、语境、互动** 八项逐项判定，不能只看“答案对不对”。
2. 系统自动检查先于人工审核：必填字段、题型结构、素材有效性不通过的题目，不进入人工审核队列。系统提示“答案可能不唯一”“级别可能偏高”的，审核人必须给出明确结论。
3. 每个不合格项都要在 CMS 中打对应问题标签，并选择严重程度和处理方式（直接修改／退回修改／再生成／弃用）。
4. 审核人可直接修改一般问题；严重及以上问题修改后需由另一位审校人员复核，不得自改自过。
5. 本标准只管题目内容。片中互动题的出现位置、互动视频画面由内容侧按《题目测评标准－内容侧》审核。

## 二、严重程度定义

| 等级 | 定义 | 处理 |
|-|-|-|
| 致命 | 答案错误、答案不唯一、考查内容与知识点无关、含不当或冒犯内容 | 一票否决，不得发布；退回或弃用 |
| 严重 | 超出目标等级明显、题型不在已确认范围、题干歧义导致多数用户无法判断、剧透 | 必须修改并复核后才能通过 |
| 一般 | 干扰项偏弱、反馈不完整、措辞不自然但不影响作答 | 审核人可直接修改后通过 |
| 建议 | 可以更好但不影响质量，如例句更贴近剧情 | 记录，不阻断 |

## 三、八项审核标准

### 3.1 知识点

| 项 | 内容 |
|-|-|
| 标准 | 题目考查对象是绑定的主知识点；知识点 ID 存在且状态为“可用”；义项与剧本台词中的义项一致；短语整条考查，不拆成单词 |
| 合格示例 | 知识点 verify your identity，题目考 verify 在“确认身份”语境中的用法 |
| 不合格示例 | 绑定 verify your identity，题目却考 passport 的拼写（考查对象偏离，致命） |
| 严重程度 | 偏离主知识点：致命；义项与台词不一致：严重 |

### 3.2 题型

| 项 | 内容 |
|-|-|
| 标准 | 题型属于《各级别题型详细设计》中该等级、该学习方式“已确认”的题型；题型结构（选项数、词块数、素材）符合规格；同一知识点的候选题覆盖约 3 种不同题型 |
| 合格示例 | B2 全英文学习，围绕同一知识点产出听音选择、语境填空、句子排序 |
| 不合格示例 | B2 生成“跟读评分”题（待确认题型，严重）；A2 句子排序拆成 6 块（结构不符，一般） |
| 严重程度 | 使用待确认或不适用题型：严重；结构细节不符：一般 |

### 3.3 语言

| 项 | 内容 |
|-|-|
| 标准 | 题干、选项、反馈无拼写、语法、标点、冠词错误；英文自然，无翻译腔；母语辅助学习的中文表述准确、简洁 |
| 合格示例 | “Without your passport, I cannot ____ your identity.” |
| 不合格示例 | “Without passport, I can not ____ you identity.”（冠词、拼写、物主代词错误，严重） |
| 严重程度 | 影响理解的语法错误：严重；标点、大小写：一般 |

### 3.4 等级

| 项 | 内容 |
|-|-|
| 标准 | 题干、选项、反馈中除知识点外，词汇不高于目标等级，句长与语法复杂度符合目标等级；可回查《英语 CEFR 分级知识库》 |
| 合格示例 | B2 题中释义用 “to check that something is true” |
| 不合格示例 | B2 题释义写成 “to substantiate the veracity of a claim”（C1／C2 词汇，严重） |
| 严重程度 | 非知识点词汇高出目标等级 2 级及以上：严重；高 1 级且影响作答：一般 |

### 3.5 选项

| 项 | 内容 |
|-|-|
| 标准 | 只有一个正确答案；干扰项词性、长度、形式与正确项一致；干扰项有迷惑性但明确错误；不使用知识点“易错点”中标注为不可作干扰项的表达；选项不暴露答案（如唯一一个与题干语法匹配） |
| 合格示例 | verify／report／borrow／explain，只有 verify 与 identity 搭配成立 |
| 不合格示例 | verify／confirm／check／believe：confirm、check 在句中也成立，答案不唯一（致命） |
| 严重程度 | 答案不唯一或答案错误：致命；干扰项过弱一眼排除：一般 |

### 3.6 题干

| 项 | 内容 |
|-|-|
| 标准 | 指令清楚，用户一眼知道要做什么；题干只有一个空或一个问题；不含提示答案的词；长度适合移动端（英文题干一般不超过 25 词） |
| 合格示例 | 剧情理解题：“为什么 Jacob 不能让 Sophia 入住？” |
| 不合格示例 | “Jacob 因为无法 verify 身份而不让 Sophia 入住，这是为什么？”（题干泄露答案，严重） |
| 严重程度 | 题干歧义或泄露答案：严重；指令不规范：一般 |

### 3.7 语境

| 项 | 内容 |
|-|-|
| 标准 | 题目语境与剧情一致，人物、地点、事件不矛盾；文本练习题脱离视频也能独立作答；片中互动题只依赖时间点之前已出现的信息，不剧透后续 |
| 合格示例 | 剧后练习题用完整句子交代“护照被偷，不能确认身份”的语境 |
| 不合格示例 | 在 Sophia 认出面具舞伴之前的题目中出现“because they met at the carnival”（剧透，严重）；文本题写“刚才 Jacob 说了什么？”（依赖视频，严重） |
| 严重程度 | 剧透、与剧情矛盾：严重；语境略单薄但可作答：一般 |

### 3.8 互动

| 项 | 内容 |
|-|-|
| 标准 | 答对、答错反馈都齐全；答错反馈说明“为什么错”而非只给答案；片中互动题的讲解文案与互动视频讲解一致，可在答对／答错讲解时长内读完；音频、图片与题目匹配可播放 |
| 合格示例 | 答错反馈：“正确答案是 verify。verify your identity 指核实身份；report 是报告，不能和 identity 这样搭配。” |
| 不合格示例 | 反馈只写“错误，正确答案是 A”（一般）；听音选择的音频是另一句台词（致命） |
| 严重程度 | 素材与题目不匹配：致命；反馈缺失一个分支：严重；反馈过简：一般 |

## 四、评分与通过规则

### 4.1 单题评分

每项按 0／1／2 分评定，满分 16 分：

| 分值 | 含义 |
|-|-|
| 2 | 完全符合标准 |
| 1 | 仅有一般或建议级问题，已修改或可接受 |
| 0 | 存在严重或致命问题 |

### 4.2 通过规则

| 结论 | 条件 |
|-|-|
| 通过 | 无致命、无严重问题，且总分 ≥ 14；其中“知识点”“选项”两项必须为 2 分 |
| 修改后通过 | 仅有一般问题，修改后重新评分满足通过条件 |
| 退回修改 | 存在严重问题，或总分 10–13 |
| 弃用／再生成 | 存在致命问题，或总分 < 10；同一题第二次退回仍不通过的直接弃用 |

### 4.3 批次规则

- 同一生成批次抽检比例不低于 30%，抽检通过率 < 70% 时整批退回，并在 CMS 中按问题标签反馈给出题 Agent 维护人优化 Prompt。
- 每个核心知识点至少保留 1 道审核通过的文本练习题，否则该知识点不能进入课程组装。
- 教研负责人在 Step 17 签字前，抽查每集片中互动题与本集所有核心知识点的文本题。

## 五、审核记录字段

| 字段 | 说明 |
|-|-|
| 题目 ID／版本 | 被审核的题目及版本号 |
| 八项得分 | 每项 0／1／2 |
| 问题标签 | 知识点错配、题型不符、语言错误、级别偏难、答案不唯一、干扰项弱、题干不清、剧透、反馈缺失、素材错误等 |
| 严重程度 | 致命／严重／一般／建议 |
| 处理结论 | 通过／修改后通过／退回修改／弃用／再生成 |
| 审核人／复核人 | 严重及以上问题必须有复核人 |
