# 剧本 Skills 仓库说明（README）

> 本文为模拟重建的示例文档：原件为项目内部资料、未随资料包公开，此处根据资料包其他文档的上下文重建，结构与方法可参考，具体数字与细节为示意。

> **定位：**这是《课程制作上线全过程（18 步）》Step 2 中“Skill 地址：（内部 Skill 仓库）”所指的仓库首页说明。仓库集中存放剧本生产链路上的 AI 岗位（Skill / Agent）定义，对应 [AI 岗位手册](../../04_表格CSV/07_AI岗位手册.csv) 中的“翻译 + 审核 Skill”“分级改写 Skill”，以及 Step 6 前置的知识点匹配。出题 Agent 另有仓库，不在本文范围。

## 一、仓库结构

```text
script-skills/
├── README.md                     # 本文件
├── CHANGELOG.md                  # 每个 Skill 的版本变更记录
├── shared/
│   ├── cefr-ratio.yaml           # B1/B2/C1 台词词汇占比阈值（与语言要求文档同源）
│   ├── kp-count-rule.yaml        # 约 90 词/知识点、±1 浮动、每集最多 3 个
│   ├── hard-errors.md            # 拼写/冠词/搭配/翻译腔等硬伤清单
│   └── output-schema.json        # 各 Skill 统一的 JSON 输出结构
├── skills/
│   ├── script-translate/
│   │   ├── SKILL.md              # 翻译 Skill
│   │   └── examples/2-1_B2.md
│   ├── script-review/
│   │   ├── SKILL.md              # 审核 Skill（全文见第四节）
│   │   └── checklists/
│   ├── cefr-rewrite/
│   │   ├── SKILL.md              # CEFR 分级改写 Skill（Agent）
│   │   └── level-shift-rules.md  # 只允许上下调整 1 级
│   └── kp-match/
│       ├── SKILL.md              # 知识点匹配 Skill
│       └── lemma-map.md          # 词形 → Base Word 归一规则

    └── run_eval.md               # 每次改 Skill 后的回归方法
```

编剧 Agent 的 Prompt **不放在本仓库**，以 [剧本语言与知识点要求（含编剧 Agent Prompt）](../剧本语言与知识点要求_含编剧Agent_Prompt.md) 第八节为唯一来源；`shared/cefr-ratio.yaml` 中的阈值必须与该文档保持一致，修改时两边同步，并在 `CHANGELOG.md` 记录。

## 三、各 Skill 说明

### 3.1 翻译 Skill（script-translate）

| 项目 | 说明 |
|-|-|
| **用途** | 把审核通过的中文源剧本按目标等级生成英文初稿，保留剧情、人物关系和情绪线。 |
| **输入** | 中文源剧本（按集/场）、人物表、目标等级（B1/B2/C1）、[台词翻译参考库](./英语剧本台词翻译参考库.csv)。 |
| **输出** | 目标等级英文稿（逐句双语对照）、待标黄候选清单、自检说明。 |
| **调用约束** | 一次只处理一集；不得增删剧情节点；参考库命中句优先采用对应等级译法；角色名、专名保持原文。 |
| **失败回退** | 由审核 Skill 判定；不通过则带审核报告回到本 Skill 重新翻译，同一集最多自动重试 3 次，仍不通过转人工（本土化专家）。 |

### 3.2 审核 Skill（script-review）

| 项目 | 说明 |
|-|-|
| **用途** | Step 2 的出口闸门：检查剧情忠实、角色一致、语言等级、知识点合规和语言硬伤。 |
| **输入** | 中文源剧本、英文稿、目标等级、对应等级知识库（只读“可用”状态条目）。 |
| **输出** | 结构化审核报告（通过/不通过、问题清单、逐句定位、修改建议）。 |
| **调用约束** | 只判不改：不直接改写台词；结论必须引用台词位置；不能凭经验判定词汇级别，知识点必须回查知识库。 |
| **失败回退** | 不通过 → 返回 Step 2 由翻译 Skill 重译；Step 5 辅助检查发现的剧情/等级问题 → 返回专家或 Step 4。 |

### 3.3 CEFR 分级改写 Skill（cefr-rewrite，Agent）

| 项目 | 说明 |
|-|-|
| **用途** | 以专家基准稿为唯一剧情基准，生成相邻等级版本（如 B2 → B1、B2 → C1）。 |
| **输入** | 专家改写基准级剧本、目标等级、`level-shift-rules.md`、目标等级知识库。 |
| **输出** | 目标等级待优化剧本、标黄知识点列表（格式 “第 X 集：LEVEL-Base Word”）、词汇占比自检。 |
| **调用约束** | 只调整词汇、句长、语法复杂度；不改剧情、人物关系、关键信息；一次只跨 1 级；改写后自动调用审核 Skill 复检。 |
| **失败回退** | 复检不通过 → Agent 内部最多自修 2 轮；仍不通过 → 退回 Step 4 人工指定问题集重跑；涉及剧情偏移 → 退回专家。 |

### 3.4 知识点匹配 Skill（kp-match）

| 项目 | 说明 |
|-|-|
| **用途** | 从正式台词中提取候选知识点，回查对应等级知识库，输出带 ID 的候选池。 |
| **输入** | 各等级完善版正式剧本、[英语 CEFR 分级知识库](./英语CEFR分级知识库.csv)。 |
| **输出** | 候选知识点清单：知识点 ID、Base Word、台词词形、台词位置、命中方式（原形/词形/短语整条）。 |
| **调用约束** | 只取角色正式台词；词形标回 Base Word；短语必须整条命中；状态非“可用”的条目只提示不入池。 |
| **失败回退** | 候选池数量低于“对白词数 ÷ 45”时，标记该集交教研人工补充或回 Step 5 建议改写台词，不得放宽命中规则。 |

**示例（第二集 2-1，B2）：**kp-match 输出 KP-B2-0388 report a theft、KP-B2-0412 verify your identity、KP-B2-0957 under the law（词形 under Italian law）；check in 命中的是 B1 条目 KP-B1-0233，因等级不符只作提示，不入 B2 候选池。

## 四、审核 Skill 的 SKILL.md 全文

````markdown
---
name: script-review
description: 审核英语学习短剧的目标等级英文稿。在翻译 Skill 或分级改写 Skill 产出后调用，判断能否进入本土化专家环节。只输出审核结论，不改写台词。
version: 1.8
---

# 审核 Skill

## 你要做什么
对照中文源剧本，审核一集目标等级英文稿，输出“通过 / 不通过”和问题清单。

## 输入
- source_zh：中文源剧本（单集，含场次、动作提示）
- draft_en：英文稿（逐句双语）
- target_level：B1 | B2 | C1
- kb：对应等级知识库条目（只含状态 = 可用）

## 审核项（按顺序执行，任一阻断项失败即判不通过）
1. 剧情忠实【阻断】：剧情节点、因果、人物关系与 source_zh 一致，无增删。
2. 角色一致【阻断】：称呼、语气、关系距离与人物表一致。
3. 标黄知识点【阻断】：每个标黄项必须在 kb 中按 Base Word 精确查到；
   词形需能归一到 Base Word；短语必须整条命中；
   括号动作、舞台描述、角色名、专名不得标黄。
4. 知识点数量【阻断】：约 90 个正式台词词 / 1 个，允许 ±1，每集最多 3 个。
5. 词汇占比【警告】：按 shared/cefr-ratio.yaml 判断，单集目标级别词 10%-25% 可接受。
6. 语言硬伤【阻断】：拼写、语法、标点、冠词、固定搭配、说话人标注，见 shared/hard-errors.md。
7. 自然度【警告】：翻译腔、语域不匹配、单句超过 18 词、角色长独白。

## 输出格式（JSON）
{
  "episode": "2-1",
  "target_level": "B2",
  "verdict": "pass | fail",
  "word_count": 0,
  "issues": [
    {"check": 3, "severity": "block", "line": 8,
     "text": "原台词", "problem": "问题说明", "suggestion": "修改建议"}
  ],
  "kp_list": ["B2-verify your identity"]
}

## 规则
- 只判不改：suggestion 写方向，不输出整句改写稿。
- 每条问题必须带 line（台词序号），无法定位的问题不得写入。
- 不得凭经验判断词汇级别；kb 查不到即视为未命中。
- verdict = fail 时，调用方会把本报告连同 draft_en 退回翻译 Skill 重译。
````

## 五、维护与回归

| 规则 | 说明 |
|-|-|
| 改动审批 | 任何 SKILL.md 改动需教研负责人和本土化专家各一人确认后合并。 |
| 回归基准 | 每次改动后用 `evals/golden/` 中的专家改写稿回归：审核 Skill 对专家稿必须判 pass，对预埋错误稿必须逐条检出。 |
| 阈值同源 | 词汇占比、知识点数量阈值只在 `shared/` 维护一份，各 Skill 引用，不在 SKILL.md 里写死数字（第四节示例为便于阅读而展开）。 |
| 知识库版本 | 知识点匹配与审核读取的知识库须记录版本号；知识点被“暂停使用/已废弃”后，已入池候选在下次运行时自动剔除并提示。 |
