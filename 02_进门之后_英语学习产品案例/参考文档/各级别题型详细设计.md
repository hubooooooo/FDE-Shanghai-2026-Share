## 一、使用规则

1. 出题前**先确定学习方式，再确定等级**，然后只能从下表对应格子里选“已确认”题型。
2. 每个核心知识点原则上覆盖 **3 种不同题型**；同一格子已确认题型不足 3 种时，可借用相邻低一级的已确认题型，需在生成说明中注明。
3. “待确认”题型在 CMS 中不可被生成任务选中，也不可发布；试验需走灰度并由教研负责人单独审批。
4. 题型名称以本文为准，CMS 题型枚举与本文一一对应（见第四节）；不得在生成任务中自造题型名。
5. 剧情理解题不属于知识点题型，只用于片中互动题，所有等级、学习方式通用，规格见 3.9。

## 三、各题型规格

### 3.1 词义选择

| 项 | 规格 |
|-|-|
| 题干 | 给出含知识点的台词原句，知识点加粗；问“该表达在句中的意思是？” |
| 选项 | 4 选 1。全英文学习为英文释义（释义用词不高于目标等级）；母语辅助学习可为中文释义 |
| 答案 | 唯一；释义须与句中义项一致，而非词典首义 |
| 反馈 | 答对：强化义项 + 例句；答错：说明所选释义为何不符合语境 |
| 素材 | 无；作片中题时引用对应台词片段 |
| 示例（B2） | “I cannot **verify** your identity.” → to check that something is true or correct |

### 3.2 听音选择

| 项 | 规格 |
|-|-|
| 题干 | 播放音频（原剧台词片段或标准朗读），问“你听到的表达是？”或“这句话的意思是？” |
| 选项 | 4 选 1；干扰项与正确项发音或拼写相近（如 verify／varied／very far） |
| 答案 | 唯一 |
| 反馈 | 显示原句文本并重播关键部分；答错时标出易混音 |
| 素材 | 必需音频，时长 2–6 秒；片中题优先截取剧集原声，信噪比不足时改用标准朗读 |

### 3.3 语境填空

| 项 | 规格 |
|-|-|
| 题干 | 一句或两句含空格的语境句，语境须能唯一推出答案 |
| 选项 | B1 及以上 4 选 1；A2 为 2 选 1。干扰项词性与正确项一致 |
| 答案 | 唯一；不得出现近义词也能成立的情况 |
| 反馈 | 答对：说明搭配；答错：说明所选词为何在此语境不成立 |
| 素材 | 无 |
| 示例（B2） | “Without your passport, I cannot ____ your identity.” 选项 verify／report／borrow／explain，唯一答案 verify（confirm、check 等可成立的近义词不得作干扰项） |

### 3.4 拼写填空

| 项 | 规格 |
|-|-|
| 题干 | 语境句 + 首字母提示（如 v_____），可附中文提示（仅母语辅助学习） |
| 输入区 | 自由输入，大小写不敏感；不接受变形以外的近义词 |
| 答案 | 标准写法 + 允许的词形（如 verify／verified 依语境只接受一个） |
| 反馈 | 显示正确拼写，标出用户拼错的字母位置 |

### 3.5 句子排序

| 项 | 规格 |
|-|-|
| 题干 | “请把词块排成正确的句子”；母语辅助学习可附中文句意 |
| 选项 | 词块 4–7 块（A2 ≤ 4 块），知识点短语保持为一个整块，不拆开 |
| 答案 | 唯一合法顺序；有两种合法语序的句子不得使用 |
| 反馈 | 显示完整句子和朗读音频 |
| 示例（B2） | I / need to / verify / your identity → I need to verify your identity. |

### 3.6 看图选词 / 中文释义选择 / 中英配对

| 题型 | 题干 | 选项 | 素材 | 备注 |
|-|-|-|-|-|
| 看图选词 | 一张图 + “这是什么？” | 2–3 选 1 英文词 | 必需图片，由设计团队提供或从剧集截帧 | 仅 A2，适合具象名词 |
| 中文释义选择 | 英文句子，知识点加粗 | 4 个中文释义 | 无 | 仅母语辅助学习，A2–B2 |
| 中英配对 | 4 组英文表达 | 4 组中文释义，连线配对 | 无 | 仅母语辅助学习 A2–B1，四组须来自同一集或相邻集 |

### 3.7 同义替换（B2、C1）

题干给出台词原句并划出一段，要求选出意思最接近、且语域相当的替换表达；4 选 1；反馈须说明语域差异。例：“I have to **report a theft**.” → tell the police something was stolen。

### 3.8 语用判断（C1）

题干描述情境和说话人意图，问“哪一句最得体／最符合角色此刻的态度？”；4 选 1，干扰项语法正确但语气、礼貌程度或隐含态度不符；反馈须解释语气差别。

### 3.9 剧情理解题（片中互动题专用）

| 项 | 规格 |
|-|-|
| 考查 | 人物、事件、原因三类；只考时间点之前已出现的信息 |
| 题干 | 全英文学习用英文；母语辅助学习用中文题干，选项可中英对照 |
| 选项 | 3–4 选 1；干扰项须是剧中可能但未发生的情况 |
| 反馈 | 答对／答错讲解均须给出原因，尽量回扣核心知识点 |
| 示例 | “为什么 Jacob 不能让 Sophia 入住？” → 因为她没有护照，Jacob 无法确认身份 |

## 四、CMS 题型枚举对照

| 本文题型 | CMS 枚举 | 题型结构校验 |
|-|-|-|
| 词义选择 | 单选-词义 | 4 选项，1 答案 |
| 中文释义选择 | 单选-中文释义 | 4 选项，1 答案，学习方式必须为母语学英语 |
| 看图选词 | 单选-看图 | 2–3 选项，1 图片 |
| 听音选择 | 听音选义 | 4 选项，1 音频 |
| 语境填空 | 语境填空 | 2 或 4 选项，1 答案，题干含 1 个空 |
| 拼写填空 | 拼写填空 | 无选项，答案 1 条 |
| 句子排序 | 排序 | 4–7 词块（A2 ≤ 4） |
| 中英配对 | 配对 | 4 组 |
| 同义替换、语用判断 | 单选-同义／单选-语用 | 4 选项，1 答案 |
| 剧情理解题 | 单选-剧情 | 3–4 选项，必须绑定剧集 ID 与时间点 |
| 跟读评分、情景复述 | 跟读／复述 | 当前禁用 |

## 五、B2 示例：verify your identity 的三种题型

按 B2 已确认题型，围绕同一知识点 ID 生成：听音选择（可作片中互动题）、语境填空、句子排序；文本题库再补一道词义选择，供剧后练习换题型使用。四道题保留同一知识点 ID，题型互不重复。
